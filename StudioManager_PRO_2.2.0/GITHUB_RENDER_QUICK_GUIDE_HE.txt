מדריך קצר – העלאת Studio Manager Online לאינטרנט
==================================================

למה הקישור השני לא נפתח?
הקובץ guest.html הוא תבנית לעמוד הזוג. הוא אינו נפתח לבדו. השרת מציג אותו רק כשנכנסים לקישור אישי /p/<token> שהמערכת יוצרת.

הדרך המוכנה בחבילה משתמשת ב-GitHub + Render:

א. העלאה ל-GitHub
1. היכנס ל-github.com וצור חשבון אם אין לך.
2. לחץ New repository.
3. תן שם כגון studio-manager-online, בחר Private וצור Repository.
4. פתח את התיקייה StudioManager_Online_v2 במחשב.
5. העלה את כל התוכן שבתוך התיקייה למאגר (server.js, package.json, render.yaml, README_HE.txt, ותיקיות public ו-data). אל תעלה מפתח סודי.
6. בצע Commit changes.

ב. יצירת שרת ב-Render
1. היכנס ל-render.com וצור חשבון.
2. לחץ New > Blueprint.
3. חבר את GitHub ובחר את המאגר studio-manager-online.
4. אשר את יצירת השירות לפי render.yaml.
5. התוכנית בקובץ היא תוכנית בתשלום עם דיסק מתמשך. זה מכוון: אסור להשתמש בשירות חינמי עם מערכת קבצים זמנית לשמירת חוזים וחתימות.
6. המתן שהשירות יעלה ל-Live והעתק את כתובת האתר שקיבלת, לדוגמה https://studio-manager-ofir.onrender.com.
7. פתח את הכתובת בתוספת /healthz. אם מופיע JSON עם "ok":true, השרת פועל.
8. ב-Render, פתח את השירות > Environment והעתק את הערך של STUDIO_ADMIN_KEY. שמור אותו פרטי.

ג. חיבור באפליקציה
1. פתח את מערכת הניהול (עמוד הבית של השרת או הקובץ המקומי במחשב).
2. היכנס להגדרות > קישורים אישיים לזוגות.
3. הדבק את כתובת Render בשדה כתובת האתר הציבורי.
4. הדבק את STUDIO_ADMIN_KEY בשדה מפתח מנהל פרטי.
5. לחץ שמירת חיבור ואז בדיקת חיבור.
6. רק אחרי הודעת חיבור תקין, פתח אירוע ולחץ יצירת קישור אישי לזוג.

ד. שליחה ובדיקת חתימה
1. שלח לזוג את הקישור האישי שנוצר, לא את guest.html.
2. הזוג בוחר חבילה, מעדכן פרטים, קורא את ההסכם, בוחר הסכמה לפרסום וחותם בשני המקומות.
3. במערכת שלך פתח את האירוע ולחץ בדיקת חתימה ועדכון האירוע.
4. בדוק שהשמות, הטלפון, הדוא״ל, תעודת הזהות, הכתובת, ההערות, החבילה והחתימות נשמרו.

לעולם אל תשלח ללקוחות את מפתח המנהל. אל תדביק אותו בצ'אט. הוא מיועד להגדרות המנהל בלבד.
