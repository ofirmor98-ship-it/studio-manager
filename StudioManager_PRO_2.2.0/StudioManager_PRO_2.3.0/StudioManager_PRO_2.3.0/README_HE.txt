Studio Manager PRO 2.2.0
========================

מערכת ניהול לצילום אירועים – גרסת Web להפעלה ב-Windows או בשרת Node.js.

מה חדש בגרסה 2.2.0
------------------
1. קישור קטלוג / הצעת מחיר:
   - הלקוח רואה חבילות, תמונות ומפרטים.
   - אפשר לבחור חבילה קבועה או לבנות חבילה אישית.
   - אפשר להסתיר מחירים ולבקש מהלקוח לשלוח בחירה בלבד.
   - הבחירה חוזרת למנהל דרך השרת, וניתן לפתוח משימת מעקב להכנת הצעת מחיר.
   - אין חתימה או אישור הזמנה במסלול הקטלוג.

2. חוזה דמה:
   - יוצר קישור נפרד לבדיקה של תהליך החוזה והחתימה.
   - העמוד מציג סימון ברור שהבדיקה אינה חוזה אמיתי.
   - תוצאת הבדיקה נשארת ברשומות ההצעות של מצב הדמה ולא נפתחת כהזמנה רגילה.
   - לבדיקות נוספות יש ליצור קישור דמה חדש.

3. חוזה רגיל:
   - תהליך החוזה והחתימה נשאר נפרד מהקטלוג.
   - לאחר שהלקוח ואתה מסכימים על המחיר והמפרט, יוצרים קישור חוזה רגיל.

4. חוויית מובייל:
   - קישורי הקטלוג והחוזה מותאמים למסך טלפון.
   - בדפדפן תומך ניתן להוסיף קישור למסך הבית כחוויית Web App.
   - זו אינה אפליקציה שהותקנה מחנות Google Play או App Store.

הפעלה מקומית ב-Windows
----------------------
1. חלץ את כל תכולת קובץ ה-ZIP לתיקייה חדשה.
2. התקן Node.js 18 ומעלה.
3. הפעל את start_windows.bat.
4. פתח Chrome בכתובת http://localhost:3000.
5. לפני שימוש בקישורים ללקוחות, הגדר כתובת שרת ציבורית ומפתח מנהל חזק בהגדרות, וודא שהשרת נפרס עם HTTPS.

פרסום ללקוחות
-------------
קישורים ציבוריים עובדים ללקוחות מרוחקים רק כאשר השרת נגיש באינטרנט דרך HTTPS. הפעלה מקומית ב-localhost מיועדת לבדיקה במחשב שלך בלבד.
אם המערכת כבר מתארחת ב-Render או בשירות אחר, יש לפרוס את גרסת הקוד החדשה בשרת ולוודא שנתוני השרת הקיימים נשמרו לפני החלפה.

המלצת עבודה
-----------
א. שלח ללקוח קישור "קטלוג / הצעת מחיר" כדי שיבחר חבילה או שירותים.
ב. בדוק את בחירת הלקוח בכרטיס האירוע והכן הצעת מחיר ידנית.
ג. לאחר הסכמה על המחיר והתנאים, עדכן את פרטי ההזמנה ושלח קישור "חוזה רגיל" לחתימה.
ד. השתמש ב"חוזה דמה" רק לצורך בדיקה, עם שמות ופרטים שאינם של לקוח אמיתי.

גיבוי ושחזור
------------
לפני עדכון יש לשמור עותק של תיקיית data ושל קובץ הגיבוי המקומי. אם קיימים נתונים בשרת, יש לגבות גם את מאגר הנתונים של השרת או את Persistent Disk שלו. אין להחליף קוד בשרת בלי לוודא שהנתונים נשמרו.

הערה
----
המערכת אינה מייצרת אפליקציית Android/iPhone מקורית. אפשר להוסיף את קישור האינטרנט למסך הבית במכשירים ודפדפנים תומכים.
